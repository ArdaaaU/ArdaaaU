Performance-driven **Front-End & Web Applications Developer** with a passion for designing scalable, responsive, and visually compelling web interfaces. Experienced in modern JavaScript (ES6+), real-time architectures powered by Supabase WebSockets, interactive graphics via HTML5 Canvas 2D & Three.js (WebGL), and accessible WCAG-compliant design systems.

<summary><b>01. Futbol Turnuva Ağacı — Realtime Football Tournament & Analytics Engine</b></summary>
<br>

A full-stack, mobile-responsive football tournament management fabric featuring 5-team tournament tree brackets, automated league standing calculations, and instant WebSocket updates.

| Metric | Specification |
| :--- | :--- |
| **Tech Stack** | Vanilla JavaScript (ES6+), Supabase Realtime, PostgreSQL, Modern CSS3 Glassmorphism |

| **Security** | Role-based password-protected administrative back-office panel accessible for desktop tournament operators |

<summary><b>02. ASCII Knight — Interactive 60 FPS Physics & Audio Engine</b></summary>
<br>

A zero-dependency mathematical physics simulation and cinematic ASCII rasterizer running natively on HTML5 Canvas with procedural sound generation.

| Metric | Specification |
| :--- | :--- |
| **Tech Stack** | HTML5 Canvas 2D, Pure JavaScript (ES6+), Web Audio API, TypedArrays (Uint32Array) |
| **Live Demo** | [ardaaau.github.io/ascii-knight/](https://ardaaau.github.io/ascii-knight/) |
| **Repository** | [ArdaaaU/ascii-knight](https://github.com/ArdaaaU/ascii-knight) |
| **Physics** | Dual-frequency Bézier harmonic wave cloth physics ($w_1, w_2$) with dynamic trailing thread particle detachment |
| **Audio** | Procedural pink noise wind synthesizer, resonant bandpass filters, and LFO modulations generated via Web Audio API |
| **Performance** | 60 FPS direct pixel buffer writing using 32-bit `Uint32Array` rasterization and 3-stage bloom/glow downsampling |

Includes 5 cinematic palettes (Classic Twilight, Blood Moon, Emerald Aurora, Neon Synth, Golden Hour), glassmorphic control HUD, live FPS counters, and wallpaper snapshot exports.
</details>
